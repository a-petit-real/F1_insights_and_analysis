# The Pit Wall — web

Application Next.js portant la maquette validée de "The Pit Wall" (dernière course + prochain GP).

## Développement

```bash
cd web
npm install
npm run dev
```

Ouvrir http://localhost:3000

## Build de production

```bash
npm run build
npm start
```

## État

- Contenu et design portés fidèlement depuis la maquette (onglets, sommaire cliquable, numéro de section sticky, mise en gras des noms, aperçu de lien au survol).
- Pas encore d'authentification ni de base de données — voir `docs/ROADMAP.md`.
